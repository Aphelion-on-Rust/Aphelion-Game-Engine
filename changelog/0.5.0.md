# 0.5.0 - Editor logic

Date: 2026-11-09 | Step: 4a | Status: not compiled yet

## feat
- **editor:** `layout`: dock tree of tab groups and splits, move / close / open / resize panels,
  default layout, YAML round trip.
- **editor:** `theme`: Dark and Light (read-only), custom copies, colors saved as `#RRGGBB`.
- **editor:** `keybinds`: text action ids, rebinding with conflict check, exact modifier match,
  reset one or all.
- **editor:** `number_field`: hover / drag / cancel logic, speeds, min/max, integer, step snapping.
- **editor:** `hierarchy`: rows built by a read-only view, selection, expand, create,
  reparent (refuses parenting into its own child), delete.

## refactor
- **engine:** `View` now takes a bundle of read-only models (`type Models<'a> = (&'a A, &'a B)`)
  and a `ReadOnly` marker rejects `&mut`, so views still can't change data.

## BREAKING CHANGES
- **engine:** `View::Model` became `View::Models<'a>`. No views existed before this version.
